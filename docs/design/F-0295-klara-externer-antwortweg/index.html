Was dieser Entwurf nicht entscheiden kann

Vier Fragen bleiben offen. Sie sind hier nicht geraten, sondern so gestellt, dass ein Ja oder Nein genügt.

O1 · AN PEDI

Soll die Einwilligung überhaupt erfragt werden, solange der externe Weg nicht gebaut ist?

Heute erscheint der Zustimmungskasten, sobald der Server auf „cloud" gebunden ist (externalConsentRequired = effectiveMode === "external", klara-policy.ts:246) — die Ausführung bleibt danach trotzdem gesperrt, weil external_not_migrated zuerst greift (:250-252). Der Anwender kann also zustimmen und es passiert weiter nichts. Das Panel hat dafür sogar einen eigenen Satz: „Trotzdem gesperrt … Das entscheidet nicht dein Fenster." Um eine Erlaubnis bitten, die nichts bewirkt, ist schlimmer als gar nicht zu fragen — deshalb zeigt dieser Entwurf in Zustand A keinen Zustimmungskasten. Ob das so bleibt, ist deine Entscheidung.

O2 · AN PEDI · WORTLAUT

Darf die Einwilligung sagen „dein markierter Text", statt „dieses Dokument"?

Der heutige Satz lautet „Dafür brauche ich die externe KI — darf ich dieses Dokument senden?" (ka4FrageText, taskpane.html:2076). Hinausgehen würde aber nur die Frage, und die ist bei einer Markierung genau der markierte Abschnitt, gekappt bei 2000 Zeichen (prepareAskQuestion :984-993, WORD_ADDIN_ASK_MAX_CHARS :981; Nutzlastklasse question, klara-policy.ts:175/292). Der heutige Text verspricht mehr Abfluss, als stattfindet — das ist die sichere Seite, kostet aber Zustimmung. Der Entwurf nennt den echten Umfang und zeigt den Text im Wortlaut.

O3 · AN SANIERER / CHEF

Braucht Zustand C eine dauerhafte Kennzeichnung an der eingefügten Antwort — auch im Word-Dokument selbst?

Im Panel trägt die Antwort hier eine Herkunftszeile. Für eingefügte Vorschläge gibt es bereits eine (klara.write.provenance: „KI-formuliert — kein zitiertes KLARWERK-Wissen"). Ob eine extern erzeugte Antwort im Dokument anders gekennzeichnet werden muss als eine intern formulierte, ist eine Frage der Nachvollziehbarkeit, nicht der Gestaltung.

O4 · NICHT GESTELLT, SONDERN BEANTWORTET

Darf Klara im Add-in je die externe KI benutzen? — Ja, aber nie still.
